# my-nuvio-plugins

Plugin manifest and provider source.

After publishing the repository to GitHub, the direct raw manifest URL is:

```text
https://raw.githubusercontent.com/OWNER/my-nuvio-plugins/main/manifest.json
```

Replace `OWNER` with the GitHub account or organization that owns the repository. If you use a branch other than `main`, replace that segment as well.

The provider source is available at:

```text
https://raw.githubusercontent.com/OWNER/my-nuvio-plugins/main/providers/faselhd.js
```
